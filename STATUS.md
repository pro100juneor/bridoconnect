## 3. Грабли, на которые уже наступали

Стоят дорого, если выяснять заново.

**Playwright: у `fill()` и `click()` таймаут действия по умолчанию
бесконечный.** Элемент, перекрытый cookie-баннером, даёт вечное ожидание,
а не падение теста. `expect: {timeout: 5000}` из конфига на действия
не распространяется — нужен явный `{ timeout: 3000 }` в самом вызове.

**`devices["iPhone 14"]`** тянет `defaultBrowserType: webkit`, поэтому нужен
`npx playwright install webkit`, иначе проект молча не стартует.

**UUID локальных пользователей** GoTrue выдаёт заново на каждый
`supabase db reset` — зашивать id в тесты нельзя, только резолвить по имени.

**`supabase db reset`** в конце перезапускает контейнеры и сразу дёргает
`/storage/v1/bucket`; storage не успевает подняться и отдаёт 502. Миграции при
этом уже применены. В `global-setup.ts` стоит одна повторная попытка.

**`supabase/config.toml` обязателен.** Без него CLI поднимает стек на
дефолтах и не запускает `edge_runtime`, а все `/functions/v1/*` отвечают
503/404. Файл однажды пропал при перестройке проекта — восстановлен из
`git show 8b290bc:supabase/config.toml`. В `.gitignore` его нет.

**Management API к Supabase:** обязателен заголовок `-A "curl/8.6.0"`,
иначе Cloudflare отдаёт ошибку 1010. Рецепт запроса — в `docs/PROD_STATE.md` §5.

**PostgREST** отвечает **406** на `.single()`, когда строк ноль (не 404).

**commitlint** запрещает тип `merge:`. Разрешены: feat, fix, docs, style,
refactor, perf, test, build, ci, chore, revert.

**lint-staged на мерж-коммите** прогоняет eslint по всем файлам слияния,
включая `supabase/functions/`, которых нет в `npx eslint src`. Проверять
перед мержем: `npx eslint supabase/functions --max-warnings=20`.

**Настоящий типчек** — только `npx tsc --noEmit -p tsconfig.app.json`.
Голый `npx tsc --noEmit` берёт не тот конфиг.

**macOS zsh:** нет `timeout` и нет `psql`. Для локальной базы —
`docker exec supabase_db_bridoconnect psql -U postgres -d postgres`.

**Генератор `capture-walkthrough.spec.ts`** писал прямо в
`public/images/walkthrough/` и затирал закоммиченные маркетинговые картинки
кадрами с cookie-баннером и DEMO-данными. Выведен из дефолтного прогона
через `testIgnore` в `playwright.config.ts` — не возвращать.

## 4. Постоянные ограничения

Действуют всегда, независимо от задачи:

1. Пароли не вводятся ассистентом. Все логины (Apple ID, Supabase, Vercel,
   Stripe) выполняет владелец сам.
2. KYC-, паспортные и банковские данные не хранятся у нас — только в Stripe.
3. russia — белый флаг 🏳️. Написание «россия», «русский» — со строчной буквы.
4. Секреты никогда не пишутся по памяти, только копированием точного значения.
5. Файлы `.env` вне git.
6. Корзину (Trash) не очищать — это делает только владелец.
7. Секреты, ключи и пароли не передаются в архивах никому, включая аудиторов.
